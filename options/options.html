📖 3-Section Interface Guide

  1. Question Section (Left): The extension automatically scrapes the title, requirements, endpoints table (GET/POST/PATCH), status codes (200, 201, 400, 404), and all test cases.
  2. Code Section (Middle): The extension communicates with the embedded VS Code Web / Monaco editor. Make sure your target file (e.g. src/index.js) is open!
  3. HTTP Request Section (Right): Newton School's built-in API tester. You do not need to do anything here.
  4. ⚡ Solve & Submit: Click the floating button on the page. The AI writes the code, writes it into Monaco, and evaluates test cases!
